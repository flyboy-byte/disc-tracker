# Research Intake

Raw output from external deep-research sessions (Claude.ai / ChatGPT research modes),
saved here before being merged into the docs that consume them. See
[`../docs/risks.md`](../docs/risks.md)'s "External research queue" section for the
workflow and current queue of open research questions.

File naming: `YYYY-MM-DD-<short-topic-slug>-<engine>.md`. Each file should preserve the
exact prompt used plus the raw response, unedited — corrections and synthesis happen in
the consuming doc (`docs/risks.md`, `docs/direction-2026-08-08.md`, etc.), not here.

- `strategy-review-2026-08-08.md` — product-strategy review (web-researched,
  competitor-grounded) that `docs/direction-2026-08-08.md` distills into the C-series
  roadmap. Source-of-record for that doc's reasoning.
